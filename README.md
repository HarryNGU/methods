# Methods 3 & 4 interactive diagrams

Interactive diagrams that go with the Mathematical Methods 3 & 4 Bound Reference by Harry Nguyen.

Live at https://harryngu.github.io/methods/

- `graphs/` (01, every graph family plus tangent; `graphs/#tan` opens tangent), `tangent/` (short link that opens graphs/#tan)
- `unit-circle/` (03), `trig-graphs/` (03), `transformations/` (04), `roots/` (05, bisection and Newton; `roots/#newton` opens Newton), `derivative/` (05), `area/` (05), `binomial/` (06), `normal/` (06), `confidence/` (06).
- Shared styling in `assets/site.css`, shared helpers in `assets/kit.js`.

Plain static HTML, no build step. KaTeX is loaded from jsDelivr.
