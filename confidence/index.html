What a confidence interval means

Each sample gives a different p̂, so each gives a different interval. Some catch the true p and some miss. The confidence level is the share that catch it in the long run, which you can watch settle as you take more samples.

Each interval

A single interval either contains p or it does not. The 95% describes the method: across many samples, about 95% of intervals made this way contain p. Wider levels catch more often but give wider intervals.
